# Vox's Signal Hunt

A static browser game. Open `index.html` locally, or publish the entire folder with any static-web host.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload these files, including the `assets` folder.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will display a public website address within a minute or two.
